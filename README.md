# ShelfSync - Library Management System

ShelfSync is a responsive Library Management System developed as a BCA 5th Semester Web Development project.

The project provides a simple digital platform where users can explore books, view book details, create an account, borrow books, and track their borrowed books.

##  Live Demo

🔗 [View ShelfSync Live](https://asakaashsahu-coder.github.io/ShelfSync-Library-Management-System/)

##  Features

- Responsive website design
- Book search and category filtering
- Detailed book information
- Book prices and availability
- Borrow Book functionality
- User registration and login
- Forgot Password feature
- User profile
- Borrowed book tracking
- 14-day borrowing period
- Remaining-time tracking
- Return Book functionality
- Gallery filtering
- Contact form validation
- LocalStorage-based data management

## 📖 Book Categories

ShelfSync currently includes books from:

- Technology
- Science
- Literature
- History

ABOUT SHELFSYNC

A simpler way to experience a library.

ShelfSync is a digital library management project created to make discovering, borrowing and tracking books easier through a clean and user-friendly website.

Read. Borrow. Track. Everything in one place.

OUR PROJECT

Bringing the traditional library experience into a digital space.

ShelfSync is a web-based Library Management System designed as an easy way for users to explore a collection of books and manage their borrowing activity.

Instead of searching through a physical catalogue, users can browse books digitally, search by title or author, filter books by category and view detailed information before deciding what to read.

The system also provides user accounts where borrowed books and borrowing information can be viewed in one place.

Our idea

Keep library management simple, organized and accessible through a modern web interface.

TECHNOLOGY

Built with simple web technologies.

ShelfSync uses familiar technologies to keep the project understandable, maintainable and suitable for academic development.

HTML5

Provides the structure and semantic content of the website.

CSS3

Handles the visual design, responsive layout, animations and overall appearance.

JavaScript

Adds search, filters, account actions, borrowing and interactive features.

Local Storage

Stores demo account, session and borrowing information within the browser.
